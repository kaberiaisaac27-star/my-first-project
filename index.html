How the three-source rule works
  1. Same fixture: match the competition, both teams, home/away order and scheduled kickoff. A rematch on another date is a different fixture.
  2. Same market: compare the same period and terms, including any goal line or handicap. A full-time home win is not the same as home-or-draw.
  3. Same outcome: all three sources must support the identical selection. Two out of three is not enough.
  4. Verified and current: missing, ambiguous, outdated or conflicting source entries remain unpublished until reviewed.

Example of the rule only: three matching full-time home-win selections would qualify after verification. A draw selection from one source would not. This example is not a prediction from any named service.
